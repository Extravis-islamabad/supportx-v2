- X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and frame-ancestors (no clickjacking);

- cookie flags (HttpOnly, Secure, SameSite);
- return-URL checks (no open redirect);
- no path traversal, no command injection, no SQL injection;
- no mass assignment (request schemas never bind tenant_id, role, owner or version);

- RFC 9457 errors;
- outbox and idempotent consumers;
- optimistic concurrency (83 of 97 PUT/PATCH routes);
- single-run schedule locks, PgBouncer pooling, timestamptz;
- soft deletes;

- health probes;
