# Area 9: Reports and Dashboards

## Navigation path

- **Dashboard:** left rail > Home > Dashboard tab. Home also has Scheduler, Tech Availability Chart, Tasks, Reminders, Announcements, and a "My Summary" slide-out on the right edge.
- **Reports:** left rail > More > Reports (`CustomReportHandler.fl`). Tabs are All Reports, Drill Down Analysis, Schedule Reports, Report Settings, plus a search box.

## Screens and what they do

**Home dashboard**
- Header: a dashboard-name dropdown, an All Sites filter, an All Groups filter, a full-screen button, a settings gear and "+ New".
- The My Summary strip counts requests (Overdue 4, Due Today 3, Pending 5, Awaiting Update 0), problems (Pending 2, Unassigned 4) and changes (Approved 1, Unapproved 0).
- Default dashboard "Helpdesk Dashboard" is shared, shown by a globe icon. Its widgets are:
  - Requests by Technician (table: Open, OnHold, OverDue)
  - Open Requests by Mode (pie)
  - Requests Last Week
  - SLA Violation by Technician
  - Requests Approaching SLA Violation
  - SLA Violated Requests
  - Unassigned and Open Requests
  - Open Requests by Priority
  - Requests received in last 20 days
  - Requests completed in last 20 days
- Each widget has a header menu (expand, refresh, switch chart type).
- Dashboard selector:
  - Search box and a Favourites group (empty; star any dashboard).
  - "Canned Dashboard" group, 11 entries: Activities, Asset, Change, Contract, Problem, Project, Purchase, Release, Helpdesk, Software, Zia.
  - Custom dashboards appear in their own group.
  - Next to the name there is a copy icon (clone) and a pencil (edit the dashboard).

**Reports home (All Reports)**
- Tree of folders, with folder owner, report count and an "Access to Dashboard" column.
- Toolbar: New Custom Report, New Folder, Organize Folders. Folders have delete and edit icons.
- There are 39 system folders plus any user folders. The catalogue is listed under "Built-in reports" below.

**Report view**
- Header shows company logo, title, "Generated by", created time, the date range, and "Total records".
- Paged output. "Export as" and "Print Preview" sit at the top right.

**Drill Down Analysis.** A mind-map style tool on requests. Fields:
- "Requests by" date field (Created Date by default).
- Period: Today, Yesterday, This/Last week, This/Last month, This/Last quarter, or a custom range.
- After Apply, a header shows totals (e.g. Total 41, Pending 28, Completed 13, SLA Violated 18).
- A root node "Requests (41)". Clicking it offers a dimension list (Site, Group, Department, Requester, Technician, Resolved By, Priority, Category, Sub Category and more).
- Picking one fans out child nodes with counts. For Priority these were Not Assigned 13, High 8, Low 8, Medium 6, Normal 4, Critical 2. Clicking a child lets you drill further.

**Schedule Reports tab.** A list with columns Report Name, Next schedule, Owner, Mail ID(s), plus a "New Scheduled Report" button. It is empty.

**Report Settings tab** (viewed, not saved):
- Tabular column widths: Small Text 130, Large Text 190, Date 100, Time 100, Number 80 (px).
- General: Disable links in report, One group per page, and "Replace empty value as" (Not Assigned).
- Matrix cell width 90 and height 30.
- Date format (`MM-dd-yyyy HH:mm`) and a group date format, with a symbol legend alongside.

**Tabular wizard** (five collapsible steps):
1. Select columns to display. A searchable checklist of about 125 request columns (including additional fields, requester and technician details, asset details, resolution, times) and a "Selected Columns" list with up and down ordering. A "Group" option also appears.
2. Filter Options.
   - Date Filter: a date column (Created Time, Responded Date, Due By Time, Completed Time, Assigned Time, Resolved Time, Last Updated Time, asset dates, impact and schedule times, Response Due By) and a period. Periods are Today, This week/month/quarter/year, Yesterday, Last 7 days, Last week/month/quarter, Last 30 days, Last 6 months, Last 12 months, Last year, Tomorrow, Next 7 days, Next week/month/quarter, Next 30 days, Next 6 months, Next year, or a custom From/To.
   - Advanced Filter: rows of column, criteria, value, with AND/OR between rows and +/− buttons. Criteria are is, is not, contains, not contains, start with, end with, is empty, is not empty. There is a value lookup picker.
3. Group by Options. A group-by column (the same column list as the column chooser) and up to a few "order by" selectors.
4. Select summary type. A grid per numeric/ID column with checkboxes: Count, Sum, Average, Maximum value, Minimum value.
5. Charts. A chart type selector: PieChart 3D, PieChart 2D, BarChart 2D, BarChart 3D, TimeSeries, Ring, Stacked Bar 2D, Stacked Bar 3D, Line, Area. A preview diagram shows the legend and axes.

Buttons: Run Report and Cancel.

**Matrix wizard** (two steps).
- Step 1 offers Simple Matrix (one top column and one left column, both required) or Advanced Matrix. Advanced adds a Column Grouping block (column plus a date format such as Year) and a Group by block with several levels, shown against a sample nested layout.
- Step 2 is the Filter Options described above.

**Summary wizard** (two steps).
- Step 1: pick a module (here Assets), then "Available Sub Reports" (e.g. Loan Details) into a "Sub Reports" list. Ctrl-click selects several.
- Step 2: Filter Options.

**Scan wizard:** not opened; it is aimed at historical inventory data by scan time.

**Save Report dialog:** Report Name, Description, Accessibility (Public or Private), Save-in Folder (a select of all folders with a "+" to create a new folder inline).

**New Scheduled Report:**
- A warning banner "Oops, outgoing mail server is not configured yet" shows at the top.
- Report* (pick from all reports), Format (PDF, XLSX, XLS, HTML, Inline HTML, CSV), To*, Subject, Message.
- Scheduler with Daily (time, hours, minutes, From date), Weekly, Monthly, Once.

## Actions and menus

- **Report toolbar after Run:** Edit, Save Report (or "Save report as" on a built-in report, which makes a copy), Mail this Report, Cancel. After a custom report is saved, "Schedule" replaces "Save Report".
- **Export as:** HTML, PDF, XLS, XLSX, CSV. I did not download anything.
- **Print Preview** is available. Built-in reports with a chart also show a "Graph View" toggle.
- **Report row actions** (hover): delete and edit. Edit opens the full wizard again.
- **Folder actions:** edit and delete icons on hover. Built-in folders show the same icons, but I did not use them on system folders.
- **Access to Dashboard:** a toggle on built-in report rows. It presumably publishes that report into the "Report Widgets" source for dashboards. I did not flip it.
- **Dashboard widgets:** the widget header lets you switch chart type, refresh and expand. In edit mode a widget also has a drag handle, a resize corner, a chart-type icon, an open-detail icon, edit (pencil) and remove (X).

## Configuration options

- Dashboard: layout columns, private or public, executive flag, refresh interval, SmartView, favourites.
- Per-widget: private or public access, Data Filter criteria, chart type and display format, header show or hide, table actions.
- Reports: Report Settings (column widths, empty-value text, date formats), per-report public or private access, folder.
- Setup > Users & Permissions > Roles (Area 11) holds the role permissions for reports; I did not open it here.

## Automation / triggers / rules in this area

- Scheduled report delivery by email (daily, weekly, monthly, once). It cannot be tested here because mail is not configured.
- Dashboard auto-refresh at a user-chosen interval (5 to 30 minutes) is the only automatic update. Everything else loads on open or on a manual refresh.
- I found no threshold alerts or report-based triggers in this area.

## Behaviour observed in tests

1. **Test dashboard.**
   - "ZZ-CLAUDE-TEST dashboard 1" was saved with Private access and a single Graph widget, "ZZ-CLAUDE-TEST graph widget 1" (Doughnut, Requests, grouped by Priority, Number).
   - The preview worked before saving. The legend showed Not Assigned, High, Low, Medium, Normal and Critical; the saved widget showed counts (13, 8, 8, 6, 4, 2).
   - A "Dashboard added" toast appeared and the dashboard opened with its own name.
2. **Widget visibility.**
   - The new widget defaulted to Public, while the dashboard I created defaults to Private. The two access levels are independent.
   - A saved widget can be reused on other dashboards through the Graph Widgets source list, which shows public widgets with a globe icon and my own with an edit icon.
3. **Test report.** "ZZ-CLAUDE-TEST report 1" was a Tabular report on Requests / All Active Requests, with columns RequestID and Priority.
   - It ran as "Unsaved Report", with 41 records over 2 pages. The header shows the generated-by user and timestamp.
   - It was saved to a new folder, "ZZ-CLAUDE-TEST folder", as Public.
   - It then appeared in the tree with Created by, Report Type and Accessibility columns, and a Schedule button replaced Save Report.
4. **Schedule form.** Opened, nothing saved. The mail warning shows immediately, so scheduling and "Mail this Report" are blocked without a mail server.
5. **Drill Down.** Applied "This quarter" and drilled by Priority. Totals matched the 41 requests in the report.
6. **Built-in report.** "SLA Violated requests by Group" runs on open with an automatic Created Time window of the current week, showing 10 records and a 3D bar chart.
7. **Refresh behaviour.**
   - Reports are run on demand and show a generated-at time stamp.
   - Dashboard widgets load on open, can be refreshed manually (an icon on each widget), and optionally auto-refresh.
   - The widget Preview has its own Refresh link. Nothing updates live by push.

## Edition notes

Enterprise trial. All report types and widget sources were available. The product has no raw SQL "query report" type. The four types are Tabular, Matrix, Summary and Scan. The Zia dashboard exists but its data depends on Area 10 settings; I dismissed the "Enable Ask Zia" popup that appeared on the dashboard and did not enable it.

## Weak spots / confusing UX

- A new dashboard is Private while a new widget is Public, which is easy to get wrong.
- The Save dialog only lists system folders until you create one with the small "+"; saving into a system folder is the default.
- The "Access to Dashboard" column shows toggles only on built-in report rows and "-" elsewhere, with no explanation.
- The Report wizard's collapsed numbered steps hide errors; Run Report works with defaults (a filter column chosen but no value ran without a warning).
- Filter "During" defaults to "Today" with the date column unset, so the date filter is easy to misread.
- Schedule form shows the mail-server error only as a banner while still allowing every field to be filled.
- Drill-down is limited to requests; there is no equivalent for problems, changes or assets.
- The column picker has 125 entries in one flat list.
- Chart types differ between widgets (2D and 3D pie) and reports (Doughnut, Pyramid, Dial), so the same data looks different in each place.

## Limits of this area

- I did not toggle "Access to Dashboard" or the Executive Dashboard flag, to avoid changing shared configuration.
- Report sharing beyond Public and Private (per-role or per-group) was not found in the Save dialog. Who can see or edit reports is probably controlled by role permissions in Area 11, so that needs a second look there.
- Scan reports were not opened.
- No export file was downloaded.
- Visibility to a non-admin technician could not be tested with only one account.
