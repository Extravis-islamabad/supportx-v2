### 2026-11-11 — WP-046a S1, PR 1: task details, dependencies, templates and My tasks (lane A)

Migration 0141 (expand only; the downgrade refuses while any tenant uses it). No new event.

- **Task details (REQ-INC-073):**
  - type, scheduled and actual start and end, estimate, percent done, extra cost, and a
    reminder some minutes before the scheduled start;
  - an end before its start is refused (AC1), and checked together with what the task has now;
  - a new start or offset clears the "reminded" mark, so it reminds again. The reminder sweep
    itself is PR 2.
- **Extra cost (the coordinator):**
  - shown only to those who may edit the record;
  - left out of "my tasks" and of a task-only owner's answers;
  - S3 decides task and worklog cost visibility together.
- **Dependencies (REQ-INC-075):**
  - `PUT /{type}/{id}/tasks/{task}/dependencies`, for the same record's tasks, at most 20;
  - a loop is refused (AC3);
  - starting or completing a task whose predecessor is open is a 409 `task_blocked` naming the
    first one (AC1);
  - the closing settings' new switch turns this into a warning;
  - the list shows "waits for …" and refreshes live on the record channel (AC2).
- **Task templates (REQ-INC-074):**
  - per type, one task or a set of up to 20;
  - admins (`config.service_desk` or `settings.manage`) keep them, audited;
  - technicians add one from the task list, each task ready to edit (AC1);
  - a disabled template is not offered and cannot be added (AC2).
- **Record template tasks (REQ-INC-040):**
  - a template's `tasks`, each with an optional condition (a filter over the list fields);
  - when a record is made, the matching ones are added, and history marks them as the
    template's (`task.from_template`).
- **My tasks (REQ-INC-076):**
  - `GET /my-tasks` covers every licensed type;
  - each record goes through its own view rule (or the type's task-owner setting), so a task on
    a record the person can no longer see is not listed (the coordinator's test);
  - due first, overdue marked;
  - a console page at `/my-tasks` with a nav entry, live on the personal channel.
- **Also in 0141:** the link kind check gains `caused_by_change` and the bulk action check
  `cancel` and `delete`; the enum values and their use come with PR 2.
