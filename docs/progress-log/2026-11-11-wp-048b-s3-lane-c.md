      aren't here;
    - delete is refused while a workflow has live runs;
    - the list shows each workflow's live runs.

    - the same `advance()` runs against a record's facts (read once) or sample values (up to 200

    - every command is shown and answered by hand: approve or reject, done or failed, the port to
      take;
    - waits hear a change the admin describes, and timers fire when the run's own clock is moved
      forward;
    - webhook header values are masked in what is shown;
    - nothing is written to the record, its history or the outbox.
  - **The live call (S3e):**
    - one per run, for a webhook or notify node, only on a real record;
    - workflows.manage only, audited (`automation.workflow_test_live_call`) with who, node, kind
      and record;
    - a webhook still goes from the worker (`WorkflowWebhookRequested.test_run`), and its result
      answers the test run;
    - a notify goes through the one notification engine;
    - a function is never run live.
