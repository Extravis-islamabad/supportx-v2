# D-119 (2026-10-30)

## Decision

**"Open now" dashboard numbers ignore the time filter** (product owner, QA WP-036 Q1, through the coordinator). Widgets that count what is open at this moment (an open-only filter or the open measures; "by age" included) are labelled "Now", keep "Not filtered by Time range" when a time filter is on, and never gain a created-date condition, so "Open incidents" keeps the same count under "last 7 days". The time filter applies only to trend and volume widgets. Site and group filters still apply.
