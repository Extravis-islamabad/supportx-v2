# D-158 (2026-11-11)

## Decision

**Asset linked-record counters count only the records the viewer may see** (Haider, the product
owner, 2026-11-11, through the coordinator). This overrides REQ-AST-044 AC3, which counted hidden
records ("records they may not see are counted but not listed").

- Per kind (incident, service request, problem, change, release), an asset shows two counters:
  "still worked" (open, paused, or resolved and not yet closed) and the total. Both count only
  the linked records the viewer may see; the list behind each counter lists the same records.
- One behaviour only: there is no setting, flag or parameter that counts hidden records.
- Work items answer through the port the assets module defines (`LinkedRecords`, WP-049b s4a),
  which is visible-only on every call; the assets module adds nothing to what it returns.

## Rationale

A count of hidden records is still information: it tells the viewer that records exist which
they are not allowed to see, and how many.
