# D-138 (2026-11-04)

## Decision

**Mobile app setup** (plan `docs/architecture/mobile.md`; approved by the product owner on
2026-11-03 as "D-112" before that number was taken on main, and renumbered here; the SDK choice
changed by the product owner on 2026-11-04).

1. **Expo SDK 58** (React Native 0.88.1), local builds only: no EAS Build, EAS Update or Expo
   push relay. The plan first named SDK 57; npm showed SDK 58 had been the stable release since
   2026-09-29, and the product owner chose it.
2. **React 19.3 for `mobile/` only** (SDK 58 pins 19.3.0). The web catalog stays on React 18.3.1,
   and the shared packages widen their `react` peer to accept both.
3. Dependencies approved: `expo`, `expo-router`, `expo-dev-client`, `expo-web-browser`,
   `expo-linking`, `expo-secure-store`, `expo-localization`, `react-native-mmkv`,
   `@shopify/flash-list`, `react-native-reanimated`, `react-native-gesture-handler`,
   `react-native-render-html`, `@expo/vector-icons`, `jest-expo`,
   `@testing-library/react-native`, Maestro; later `expo-notifications`, `expo-camera`. Companions
   named for veto (WP-M1): the Expo template's `react-native-screens`,
   `react-native-safe-area-context`, `expo-constants`, `expo-status-bar`; `expo-crypto` (Web
   Crypto `randomUUID` for the API client on Hermes); `jest`, `@react-native/jest-preset`,
   `test-renderer`, `@types/jest` (test peers); `zustand` (already in the stack list).
4. **Mobile sign-in keeps the BFF model:** the system browser runs the existing PKCE login, the
   callback hands a one-time code to `supportx://auth`, and the app exchanges it for the opaque
   session ID (SecureStore), sent as the session cookie with `X-CSRF-Token`. Keycloak tokens
   never reach the device. The formal ADR comes with WP-M2.
5. **Mobile session length stays as the web:** 12 h absolute (tenant overrides as today).
6. The app targets iOS and Android only (no web build): browsers use the console and portal.

## Rationale

Lets the technician and admin app use today's backend auth unchanged except for the hand-off,
and keeps on-prem and air-gapped parity (no Expo cloud services in the product).
