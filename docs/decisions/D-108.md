## Decision

**WP-033 plan approved** (knowledge authoring and publishing; plan ~/Desktop/wp-033-plan.md; D-074 defaults decided here). (1) **Articles in review are hidden from other technicians**: drafts and in-review versions only for the author, the owner, the topic owner and approvers; the KCS "work in progress for technicians" setting (REQ-KB-066) is V1 and off by default; requesters never see them. (4) **Technician visibility by group only** at MVP (no technician site audience). (5) **Notifications**: WP-023 has merged; session 2 registers the knowledge events (submitted, approved, rejected, published, withdrawn) through `app/shared/notifications/ports.py`, so approvers and authors get bell notifications; the in-app "Awaiting my approval" inbox and live counter stay. (6) **Translations**: English and Arabic at MVP, Urdu V1. (7) **Permissions**: the finer set of the plan (§8), scopes `all` and `group`; per-role free topic lists V1. (8) **Article ID prefix KB** (first number 1). (9) **Callouts approved** as a small custom Tiptap node on the existing MIT packages; the sanitiser allows `div[data-callout]` only with a value from {info, warning, tip, note} and strips any other value, with a test. Knowledge moves from lane B to lane C (LANES.md). Lane C order: WP-035-FIX, then WP-036 dashboards, then WP-033 sessions 1-4.
