# D-085 (2026-10-26)

## Decision

**Search for MVP is PostgreSQL full-text behind a search port**, with OpenSearch later as an adapter (architecture.md §5 names PostgreSQL FTS as the alternative). It includes **typo tolerance and partial matches with `pg_trgm`** for subjects and people's names ("printr" or half a name still finds results). The port stays ready for **meaning-based search**: for WP-038 (similar incidents), **pgvector in the same PostgreSQL** is the preferred first option, so permissions stay exact there too.
