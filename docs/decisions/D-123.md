# D-123 (2026-11-02)

## Decision

**One file per decision and per session-log entry** (product owner, through the coordinator,
2026-11-02). Decisions live in `docs/decisions/D-NNN.md` and session-log entries in
`docs/progress-log/YYYY-MM-DD-<slug>.md`; `docs/DECISIONS.md` and the session-log section of
`docs/PROGRESS.md` become fixed pages that hold no entries. `make decisions` and
`make progress-log` render the combined views to `docs/_build/` (not committed).
`backend/tests/test_docs_entries.py` checks that every entry is well-formed, that decision numbers
are unique, and that no entry is added to the shared pages again. Existing entries were moved
unchanged (D-097 and D-102 had no "Affected docs" cell: "(none recorded)").

## Rationale

Every lane appended to the same table and the same log, so each merge made the other lanes' open
PRs conflict and dropped them from the merge queue (after #133 every open PR was DIRTY). Separate
files only conflict when two lanes really take the same number.
