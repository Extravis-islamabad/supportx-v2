# D-068 (2026-10-24)

## Decision

**The escalating technician can keep following** an incident they hand over: by default they become a follower with read access (REQ-INC-151). The D-053 lose-access warning still applies when "keep following" is switched off.

## Rationale

Area 15: L1 could not follow up on what it escalated. Amends D-053 (WP-020).
