# D-136 (2026-11-04)

## Decision

**A one-time reset of stored layout preferences** (WP-042; the product owner, through the
coordinator, 2026-11-04).

- Existing users' stored navigation layout and form density are reset once to "not chosen"
  (NULL). The defaults (side bar, comfortable forms) then apply when read. Today there are only
  dev, QA and demo accounts; no real users yet.
- It is a per-tenant data step in a new migration (0072), never an edit of a merged one.
- **After go-live, a changed default never overwrites a stored preference** (Haider's rule, as
  in D-124).

## Rationale

0071 made the two preferences nullable, but every existing user kept the old server default as
a stored value, so they all counted as "chosen" (lane B's review). The reset makes the current
defaults apply to everyone before the pilot.
