# D-083 (2026-10-26)

## Decision

**WP-020c defaults** (stated in the WP-020c plan per D-074; the product owner gave the scope): (1) **Levels** Tier 1-4 seeded, none preselected; admins add, rename, reorder and retire (REQ-INC-007 pulled forward from V1 on request). (2) **Closure codes** fixed, workaround, no fault found, duplicate, user error (used on close in WP-020f). (3) One seeded template **"Standard incident"**, the default: subject and requester always shown and required, every other field shown and optional. (4) **Impact, urgency and priority keep their four fixed values** (D-056): admins rename and colour them and edit the matrix (saved whole; a gap is refused). (5) **Reason prompt per transition**: none / optional / required, Appendix A as the start; turning one on asks from the action's own list. (6) **Templates**: starting values fill only fields the user has not typed in; switching keeps what was typed and **asks before clearing** a filled field the new template hides; hidden fields are always listed on the form; **people are never preset** by a template; a hidden required field needs a starting value (refused on save otherwise, REQ-WI-009 AC4); the default template cannot be turned off; templates are turned off, never deleted. (7) **Form density per user** (`users.form_density`): comfortable by default; compact = two columns, labels on the left. (8) **Numbering**: the next number can only move up (never reuse an ID). (9) Pick-list values and categories are **retired, never deleted**; retired values still label old records; "Other" in a reason list cannot be retired. (10) **Reply templates** are managed in Admin › Incidents; the composer's "Manage" opens that page in a new tab so the draft stays. Deferred: REQ-INC-020 (needs the resolution field, WP-020f), REQ-INC-011 AC2/3 (SLA, WP-025), category merge (REQ-ADM-043 AC3) and the duplicate-name warning (REQ-WI-027 AC2) to WP-021, the all-types numbering page (REQ-ADM-045) when a second type exists.

## Rationale

Product owner's WP-020c scope; defaults chosen to be least surprising.
