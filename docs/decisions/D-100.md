# D-100 (2026-10-27)

## Decision

**WP-035 plan approved** (plan: ~/Desktop/wp-035-plan.md). **D1** PostgreSQL is the MVP reporting store through a read-only reporting role and pool; ClickHouse at V1 behind the same compiler; ClickHouse off on single node. **D2** On single node REQ-RPT-006 AC2 is met by separate role, pool and limits plus the save-latency load test; a replica is required only on HA profiles. **D3** Scheduled reports at MVP, minimal (users and groups, CSV/XLSX/PDF, each recipient's own scope and language), built after lane B's mail sender merges; report library, email-now and external recipients stay V1. **D4** Report builder in **Essentials** behind its own feature key (`report_builder`: the product owner's `reports.builder`, spelled like every other feature key). **D5** At MVP every widget is operational (≤ 2 s); the 60 s tier only with ClickHouse. **D6** Lane C builds the shared filter builder in `packages/forms` (generic, takes the field allowlist), lane A reuses it in WP-020d. **D7** Server-side labels: a JSON copy generated from `packages/labels`, checked in CI, used by exports, report emails and notifications (ADR-034). **D8** `openpyxl` also for **writing** XLSX (write-only mode). **WeasyPrint** approved with its companions (MPL-2.0 acceptable for unmodified use) and Pango, **only in the worker image, never the API image**, with a custom URL fetcher that refuses everything except the bundled fonts and data URIs we generate (no network, no file paths), and a test proving an external or internal URL in report content is never fetched. Fonts Noto Sans and Noto Naskh Arabic (OFL), bundled offline. `react-grid-layout` decided with WP-036. **D9** Lane A writes the incident reporting provider (`work_items/service/reporting.py`) and the report indexes in its own migration. **Added: CSV/XLSX formula injection protection**: any cell value starting with `=`, `+`, `-`, `@`, tab or carriage return is neutralised (prefixed with an apostrophe), with tests, in every export path.

## Rationale

Product owner review of the WP-035 plan.
