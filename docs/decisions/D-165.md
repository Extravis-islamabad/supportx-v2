# D-165 (2026-11-12)

## Decision

**A dedicated identity realm per Enterprise tenant (REQ-SEC-015) is deferred** (Haider, the
product owner, through the coordinator). On-prem installations are single-tenant, so they already
have a realm of their own. SaaS keeps the shared realm with Keycloak Organizations, one per
tenant, as built (WP-039, D-094). WP-057 drops it from session 6. It moves to LATER in
PROGRESS.md.

## Rationale

The shared realm already isolates tenants through Organizations, domain routing per organization
and SupportX's own tenant checks. A realm per tenant would add a second Keycloak operating model
(provisioning, upgrades, the identity service account per realm) for no V1 need. No customer
needs it before the hosted Enterprise offering exists.

## Affected docs

PROGRESS.md (WP-057; LATER), docs/specs/parity/11-admin-users-security-audit.md (REQ-SEC-015
stays specified, scheduled LATER).
