# D-021 (2026-10-23)

## Decision

Approved `cryptography` (PyCA, Apache-2.0/BSD). Session records in Valkey are encrypted with AES-256-GCM. It will also be used for licence signatures (Ed25519, WP-013) and field-level encryption.

## Rationale

Python's standard library has no AES; PyCA is the standard, audited implementation.
