# D-044 (2026-10-24)

## Decision

**Features outside the tenant's edition** (for example links to problems, changes or assets in Essentials) are **shown disabled with an upgrade hint** by default. A tenant admin can switch them to **hidden completely**. The decision comes from the entitlement interface on the server; the browser only renders it.

## Rationale

Shows what an upgrade buys without cluttering screens for tenants that do not want it.
