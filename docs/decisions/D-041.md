# D-041 (2026-10-24)

## Decision

The proposed tenant defaults in file 01 Appendix A (priority matrix, statuses, transitions, auto-close after 3 business days, 7-day reopen window, closing with open work, notifications, limits) are **approved**. **Every default in every parity module file must be editable per tenant by an admin**; defaults are seed data, never hard-coded behaviour. For MVP, D-056 narrows this: admins edit values (labels, colours, reasons, the priority matrix, prefixes, categories); adding or removing statuses and transitions waits for the V1 life cycle designer.

## Rationale

Sensible out-of-the-box behaviour without taking control away from tenants.

docs/specs/parity/README.md, 01-work-items-incidents.md (Appendix A), all later module files
