# D-025 (2026-10-23)

## Decision

New Stage 0 work package **WP-016 Authorization policy layer** (architecture.md §11.2): roles and permissions (module + action), scopes (all / site / group / own), attribute rules, field-level visibility, segregation-of-duties checks, one policy evaluation service for API, search, realtime fan-out and AI agents, compiled permissions cached in Valkey and invalidated by events; seed roles tenant admin, technician, requester. WP-012 (walking skeleton) now depends on WP-016. Parallel agent mode has ended; decision IDs D-030..D-039 (reserved for the parallel agent) are released and may stay unused.

## Rationale

The walking skeleton is the reference every later module copies; it must show real permission checks, not the interim `user_type` checks from WP-008. §11.2 had no work package in Stage 0.
