# D-001 (2026-10-22)

## Decision

Monitoring-dependent features stay in scope: pre/post change health checks, live health on CMDB impact maps, wallboards with monitoring status. SupportX may **read** health, problems and topology from the MonetX API via the `monitoring_integrations` module, read-only. SupportX still performs no monitoring, polling of devices or alert correlation.

## Rationale

Keeps the NOC-native differentiators from product-plan.md §6 without moving monitoring into SupportX. ADR-017 is unchanged.
