# D-110 (2026-10-28)

## Decision

**`react-grid-layout` approved for dashboards** (MIT; pinned 2.2.4; companions `react-draggable`, `react-resizable`, `fast-equals`, `resize-observer-polyfill`, `clsx`, `prop-types`, all MIT), with conditions: (1) the keyboard move and resize buttons stay beside dragging (accessibility, REQ-DSH-019 AC2); (2) it is lazy-loaded only in dashboard edit mode, so viewers never download it; (3) right-to-left mirroring in Arabic and Urdu is verified by an e2e test; if it cannot be made correct, RTL falls back to the swap-and-buttons layout and the reason is recorded here. Implementation: the library lays out from the left only, so in RTL each widget's column is mirrored in and out (x' = 12 - x - w) and resizing uses the bottom-left (end-side) corner; `dashboards-grid.spec.ts` checks the sides and the saved column after a drag in English and Arabic. It passed in both on the k3d cluster (run 40698838300), so no RTL fallback is needed. Urdu uses the same right-to-left path as Arabic. Also WP-035-FIX and WP-036 approved.

Product owner review of WP-035-FIX and WP-036.
