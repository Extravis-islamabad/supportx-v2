# D-082 (2026-10-26)

## Decision

**WP-022 files and safe attachments** (plan approved, ~/Desktop/wp-022-plan.md): (D1) uploads **stream through the API** (not pre-signed direct uploads), ADR-028; (D2) **per-tenant data keys wrapped by an installation key**, with **key rotation**; backup and restore must include the installation key, with a written procedure (losing it loses every file); (D3) **ClamAV optional and offline-capable**, `scan_required` **on by default**; files awaiting a scan show "scanning"; with no scanner installed, administrators see a clear warning that files are unscanned (never silent); alert when signatures are older than **7 days**; (D4) **Pillow** approved: images processed in a worker with pixel and size limits (decompression-bomb protection), GPS/EXIF stripped; (D5) files are a **shared platform service**; (D6) **`storage_gb` licence limit** (placeholder numbers); (D7) defaults as planned, **max file size admin-adjustable up to 100 MB**; (D8) **@tiptap/extension-image** approved, inline images replace lane A's placeholder; (D9) real ClamAV in e2e, a fake scanner elsewhere; (D10) **3 sessions**. Addition: **dangerous file types blocked by default** (executables and scripts such as .exe .bat .cmd .js .vbs .ps1 .sh .msi .jar), admin-editable list; the **real file type is checked**, not only the extension.

## Rationale

Product owner review of the WP-022 plan.
