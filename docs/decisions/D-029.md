# D-029 (2026-10-23)

## Decision

**SupportX's own database is the source of truth for authorisation** (roles, permissions, scopes, site/group memberships). Keycloak is used for authentication only. On a user's first login in a tenant (JIT provisioning, or the first login after WP-016 for existing users) their Keycloak realm roles are mapped **once** to initial SupportX role assignments (tenant_admin → Tenant administrator, technician → Technician, otherwise Requester); afterwards only SupportX changes them. Automatic mapping of SSO groups to roles may come later.

## Rationale

Admins manage access in the product, per tenant, without Keycloak admin rights; one policy layer (architecture.md §11.2) needs one authoritative store.
