# D-096 (2026-10-27)

## Decision

**A person's site is suggested from their department (WP-021 QA C4):** when a department is chosen and the person's site is empty, the department's site is filled in as a suggestion; a site already set is **never overwritten** and stays editable. The same rule applies to CSV and Excel imports (a site in the file or on record wins).

## Rationale

Product owner answer to the WP-021 QA report.
