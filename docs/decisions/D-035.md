# D-035 (2026-10-24)

## Decision

Approved **dayjs** (MIT) as a direct frontend dependency; it is already Ant Design 5's date library (same version, one copy in the workspace catalog). All date and time entry uses Ant Design DatePicker / RangePicker through one shared component (`DateTimeField`, `DateTimeRangeField` in `packages/ui`), in the user's profile time zone from `/auth/me` (else the browser's); values in and out are ISO instants (UTC). Native date inputs are not used.

## Rationale

One consistent, localised (en/ar/ur, RTL) picker everywhere; entering times in the profile zone matches how they are shown and filtered (X-Time-Zone).
