# D-027 (2026-10-23)

## Decision

New Stage 1 work package **WP-017 Tenant branding and domains** (planning only): per-tenant subdomain (SaaS), optional custom domain with automatic TLS, tenant resolution from the request host as a login hint, logo / favicon / brand colours on console, portal, Keycloak login page and emails, a branding admin screen, assets stored via the S3 API. The WP-010 theme already accepts per-tenant overrides.

## Rationale

Customers expect their own look and address; the design system was built so branding only adds data, not a redesign.
