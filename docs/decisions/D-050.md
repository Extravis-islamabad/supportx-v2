# D-050 (2026-10-24)

## Decision

**MonetX recovery:** by default the incident is **auto-resolved** when MonetX reports recovery. If a technician has taken the incident over, it is not resolved; instead a **"source recovered" note** is added and the **assignee is notified**. Both behaviours are configurable per tenant.

## Rationale

NOC teams want noise cleared automatically, but never under a technician who is still working.
