# D-126 (2026-11-04)

## Decision

**Dependabot updates: which merge by themselves** (product owner, 2026-11-04).

1. **Patch and minor updates of approved dependencies may be auto-merged once CI is green.**
   "Approved" means listed in CLAUDE.md §3. "Green" means every required check passes, Security
   included. They go through the merge queue like any other PR. No check is skipped or relaxed
   for them.
2. **Major updates come to the product owner.** Until the pilot, Dependabot doesn't propose
   majors for npm and uv (`.github/dependabot.yml`). Any major that does arrive, a security
   update included, waits for the product owner's decision.
3. **Security-sensitive updates come to the product owner, whatever their size:**
   - every update Dependabot raises as a security update (a GitHub advisory);
   - updates of packages that guard security or parse untrusted input:
     - cryptography and signing: `cryptography`, the licence core;
     - sign-in and sessions: Keycloak, the BFF's OIDC and session libraries;
     - HTML sanitising: `nh3`;
     - parsers of uploaded files: `pillow`, `openpyxl`, `icalendar`;
     - the ClamAV image;
   - container base images;
   - GitHub Actions that receive secrets or write permissions.
4. **Anything not in CLAUDE.md §3 is a new dependency** and needs the product owner's approval
   first (the dependency rule), whatever Dependabot calls it.

## Rationale

Patch and minor updates of already approved libraries are frequent and low-risk once the full
CI passes. Merging them by hand costs lane time, and they pile up. Majors change behaviour and
can need code changes. Security-sensitive packages and advisories decide how SupportX protects
data, so a person decides them.

## Affected docs

`.github/dependabot.yml`. A follow-up for lane B adds the auto-merge step for case 1 and the
labels for cases 2 and 3. The step must not change repository settings or permissions; it only
enables auto-merge on qualifying PRs. Until then, every Dependabot PR is merged by hand under
these rules.
