# D-139 (2026-11-04)

## Decision

**The installer asks whether to install the local AI model** (WP-037, REQ-AI-003; the product
owner, through the coordinator, 2026-11-04; option a).

- The Helm chart keeps the local model servers off by default (`ai.local.enabled: false`), so the
  single-node output and every other install stay as they are.
- The installer (WP-014c) asks the customer whether to install the local model. It shows the
  recommended choice, yes, and the size it costs: about 4 GB of memory and 3 GB of weights for
  the CPU servers.
- When the customer chooses it, the installer switches `ai.local.enabled` on, ships or fetches
  the pinned weights into the model volumes, and records the decision (in the install record or
  the audit log). Choosing no is recorded too, and AI features then stay unavailable until a
  model is configured.
- REQ-AI-003 ("a local model ships with every deployment") is met by every bundle carrying the
  model and the installer offering it, recommended, on every install.

## Rationale

A local model is a product pillar, but about 4 GB of memory and 3 GB of weights on every
single-node install is a sizing choice the customer should make knowingly. Asking at install,
with yes recommended, keeps the default sovereign setup one keystroke away without surprising
small sites.
