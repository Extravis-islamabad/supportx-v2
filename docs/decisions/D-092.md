# D-092 (2026-10-27)

## Decision

**WP-021 people and organisation (plan approved):** (1) **SupportX owns the person record** after it exists: the first sign-in creates the person or links one added by an admin or import by email; later sign-ins record only the time (name, email, type, language are no longer synced from Keycloak). (2) **Email optional**: a contact (sign-in off) needs none; signing in needs one. (3) Technician = licence seat on add, import, promotion and reactivation; deactivation frees it. (4) **Deactivation removes nothing**; reactivation keeps only the roles and groups the admin confirms; stopping sign-in or deactivating ends sessions at once. (5) **Every record belongs to a desk** (IT desk by default, D-061/D-062); more desks need ESM. (6) The licence limit **`departments` is renamed `desks`** (label "Desks"; architecture.md licence format, entitlement code, tests, labels). (7) **openpyxl** (MIT) approved for imports: read-only, values only, with file size, row, column and cell limits and a zip-bomb check, processed in the background import job. (8) The first-run **technician-visibility question** (D-073) is a tenant setting, "their groups" preselected. (9) Sites, groups and departments in use are not removed (409 with counts): make them inactive.

## Rationale

Product owner approval of the WP-021 plan.
