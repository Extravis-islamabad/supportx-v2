# D-018 (2026-10-22)

## Decision

**Temporary exception to D-015:** the `supportx-v2` repository is made public until the GitHub account billing problem is fixed (expected by 2026-10-24), then set back to private.

## Rationale

GitHub refused to start Actions jobs on the private repo ("recent account payments have failed or your spending limit needs to be increased"); public repos run on free runners, so WP-003 could be verified. Accepted risk: while public, the code and specs (including the licensing design) can be cloned or forked, and forks stay public after the switch back.
