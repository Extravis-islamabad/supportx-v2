# D-183 (2026-11-24)

## Decision

**dnspython (ISC licence) is an approved runtime dependency, for the TXT lookup behind verified
e-mail domains** (REQ-SEC-010, WP-057 S5d). Haider, the product owner, approved it through the
coordinator. Its conditions:

- The lookup uses the resolver the installation is configured with (the host's or the pod's
  resolv.conf). It never names a public resolver.
- Every lookup is bounded: a timeout per query and for the whole lookup, at most 20 TXT records
  read, and a size limit per record. Longer records are skipped, never cut short.
- Where no lookup is possible (an on-prem or air-gapped host without DNS), the existing manual
  verify stays, with a reason required and audited. It is for single-tenant installations only.
- On a multi-tenant installation, where manual verify is refused, DNS is the way a domain is
  verified, so REQ-SEC-010 AC1 is met there.

## Rationale

The standard library has no TXT lookup, and running `dig` or `nslookup` from the API is worse
(an extra binary in every image, parsing its output). dnspython is the long-standing Python DNS
library: pure Python, ISC-licensed (so it can be redistributed on-prem), with no dependencies of
its own, and it has an asyncio resolver.
