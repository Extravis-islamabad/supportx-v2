# D-087 (2026-10-27)

## Decision

**WP-026 custom fields: defaults taken while building (pending product owner review).** (1) **Types:** text, long text, whole number, decimal, amount of money (one ISO currency per field), date, date and time (stored in UTC), pick one, pick several (list or buttons), yes/no, email, phone, web address and person. **Asset and configuration item lookups wait for the assets and CMDB work packages** (REQ-INC-014 names them; nothing to point at yet). (2) **Definitions live in the metadata module** (`custom_fields`), values on each record as typed JSON by key (`work_items.custom`), as architecture.md §6.6 says; keys come from the English name, are never shown to users and are never reused, even after a field is removed. (3) **Removing a field records hold values in asks first** (`confirm=true`): it disappears from forms, lists and filters, the values stay on the records and in their history (AC4); **retiring** is offered instead and keeps the field on old records. A removed or retired field's template rules stop applying. (4) **Index on request (AC2):** an admin asks for an index; the migration job (`python -m tooling.custom_field_indexes`, also run by every deploy's migrate Job and by `make custom-field-indexes`) builds it with CREATE INDEX CONCURRENTLY as the migrator role and records "active" or "failed" on the field. (5) **Required** can be set on the field (every new incident) or by a template (its incidents); both follow D-086 (never emptied later, made-required-later blocks only emptying). (6) **Search:** the text of text, long text, email, phone and web fields is kept in `work_items.custom_text` for the WP-027 search port. (7) **Lists:** one custom-field filter (pick one, pick several, yes/no) in the incidents list now; list columns and export of custom fields come with WP-020d (views and export). (8) Admin regular-expression formats that can backtrack catastrophically (`(a+)+`) are refused. (9) Licensed with the `incident` feature while incidents are the only records with custom fields.

## Rationale

Built in WP-026 under "build unless a decision blocks you"; each default is reversible.
