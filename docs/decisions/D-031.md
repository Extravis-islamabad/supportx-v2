# D-031 (2026-10-23)

## Decision

**Navigation layout is a per-user preference:** Top bar (default), Side bar or Compact side bar (icons only), chosen under Appearance › Navigation and stored server-side (`users.nav_layout`) so it follows the user to every device.

## Rationale

ServiceDesk Plus offers the same choice (parity); the top bar leaves the full width to tables. Menus are the same in all three (permission- and licence-driven).
