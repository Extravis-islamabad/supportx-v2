# D-026 (2026-10-23)

## Decision

Approved frontend libraries: **react-router** (routing; 7.x, because 8.x requires React 19 and the stack is on React 18), **openapi-fetch** (typed fetch client from the openapi-typescript author, built on the generated `schema.ts`), **@axe-core/playwright** (accessibility checks in e2e; MPL-2.0, test-only, never shipped).

## Rationale

Routing and a typed client are needed for the app shell and every screen; axe makes the accessibility bar testable.
