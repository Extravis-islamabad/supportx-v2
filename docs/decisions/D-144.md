# D-144 (2026-11-05)

## Decision

**Change management: the product owner's answers to the WP-045 questions**, and approval ties
(Haider, through the coordinator, 2026-11-05; plan ~/Desktop/wp-045-plan.md, file 05).

1. **MVP scope.** No change record at MVP. architecture §17 wins (D-002).
2. **Default types:** all five (standard, minor, normal, major, emergency) on three models
   (standard, normal, emergency), as Appendix A says.
3. **Emergency approval:** an emergency CAB decision is required before implementation.
   - A permission-based override exists. *Added by the product owner:* the override needs a
     reason, is audited, and **forces a post-implementation review** of that change.
4. **Health checks:** compare MonetX health states and problems only, with no metrics stored
   (D-001, ADR-017). This is read-only through monitoring_integrations, and only when the
   connector is set up.
5. **Freeze windows:** none active in a new tenant.
6. **CAB meetings** (REQ-CHG-054): later.
7. **Calendar feed** (REQ-CHG-071): later. If it is ever built, it is off by default per tenant,
   through a revocable secret URL.
8. **Editions:** everything is in Professional, the standard change catalogue included.
9. **Approval ties** (WP-045b's boards, and lane C's release stage approvals alike): an exact
   split **rejects** by default. A tenant can name a deciding approver (the chair) who breaks
   ties when set. This is the same tenant option for changes and releases.

## Rationale

Changes are V1 work, so the MVP stays as planned (1). The five types cover Appendix A without
custom models (2). An emergency still gets a decision. The override exists for real emergencies,
but it always leaves a reason, an audit entry and a review (3). Health stays within the
monitoring boundary (4). A new tenant is never blocked by freezes it didn't set up (5).
Meetings and feeds wait for demand (6, 7). One edition keeps the change process whole (8). A
tie means no clear yes, so it rejects unless the tenant has named someone to decide (9).
