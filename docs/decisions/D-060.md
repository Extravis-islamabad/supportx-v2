# D-060 (2026-10-24)

## Decision

**MFA is required by default for administrators, auditors and technicians**, optional for requesters; a tenant admin can change it per role (REQ-SEC-024).

## Rationale

Staff accounts hold sensitive data; requesters should not hit a wall before raising a ticket (Area 15).
