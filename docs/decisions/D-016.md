# D-016 (2026-10-22)

## Decision

Object storage: application code uses only the S3 API (no MinIO-specific features). MinIO (`pgsty` community images) is allowed for local development only. For on-prem bundling, evaluate SeaweedFS (Apache-2.0) and other S3-compatible stores under ADR-012; SaaS uses the cloud provider's S3.

## Rationale

Official MinIO community images were withdrawn and MinIO is AGPL; an S3-only contract keeps the store swappable.
