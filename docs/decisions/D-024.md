# D-024 (2026-10-23)

## Decision

Permanent working rule: no destructive git command (`git checkout -- .`, `git restore` on unstaged work, `git reset --hard`, `git clean -f`, force push) without first saving the work with `git stash` or a commit; the same protection for data: never delete or overwrite existing data without explicit confirmation.

## Rationale

In the WP-007 session a `git checkout -- .` discarded an unstaged edit (recovered by redoing it).
