# D-095 (2026-10-27)

## Decision

**Accepted breaking API changes before the first external API release (WP-021):** breaking changes that an approved decision requires may stay on `/api/v1` while no outside client exists. Each is listed in `docs/architecture/openapi-accepted-breaks.json` exactly as the diff reports it, **with its decision and date**; the OpenAPI diff accepts only those. The mechanism is allowed **only until the first external API release (WP-041 or the first customer install, whichever comes first)**: then the list is **emptied** and `public_api_released` is set to true, and from then on every breaking change means `/api/v2`. **CI fails** (`make openapi-check`, `--check-accepted`) if the list is non-empty once the flag is set. First entries: WP-021 user `email` nullable (D-092 contacts), licence limit `departments` renamed `desks` (D-092), schemas UnitIn/UnitOut replaced by SiteIn/SiteOut/GroupIn/GroupOut. The diff also treats a new key code of a code-keyed map and a request field that accepts more as additive.

## Rationale

Product owner answer to the WP-021 CI gate question.
