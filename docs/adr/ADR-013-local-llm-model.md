# ADR-013: Local LLM model family and sizing

- **Status:** Open
- **Date:** 2026-10-22
- **Source:** architecture.md §2.10, §12, §19
- **Owner:** TBC

## Context

AI must run on-prem and air-gapped with good Arabic and English quality, on CPU-only nodes for core features and optionally on GPU.

## Decision

Recommendation: benchmark open-weight models for Arabic/English quality on CPU and GPU. Not yet decided.

## Consequences

- Sizing guidance must be published before the first on-prem AI release.

Open in architecture.md §19; decision required before the dependent work starts.
